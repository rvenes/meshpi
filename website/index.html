Det viktigaste

Bygd for å stå på heile tida

Daemonen eig sambandet. Terminalgrensesnittet kan opnast og lukkast utan at meldingar går tapt.

01

Sanntidschat

Aktiverte public-kanalar og direktemeldingar med kanalrute dukkar opp automatisk, med RF/MQTT, SNR, RSSI og ACK når data finst. Gamle kanaloppføringar blir skjulte etter kanalbyte; historikken blir bevart.

02

Heile nodelista

Opne F10 for lokal radioinfo og ei søkbar nodeliste med sist sett, batteri og GPS. Sjå detaljar eller vel kontaktar for verifisert sletting frå nodelista på den tilkopla radioen.

03

TCP, USB og BLE

Byt mellom lagra eller oppdaga Meshtastic-nodar utan omstart. BLE-støtta er eksperimentell og er live-testa på Windows og macOS.

04

Lokal historikk

Meldingar, traceroute-resultat, ulest-status og nodeinformasjon blir lagra lokalt i SQLite. Arkivering slettar ingenting, og meldingar kan tømmast etter omfang med CLI-en.

05

Valfri webserver

Vel web under installasjonen. Same daemon og historikk kan brukast frå terminalen og fleire nettlesarar; mobil og PC treng ingen separat MeshPi-klient.

06

Privat innlogging

Bruk eingongskode på localhost, eller fleire passkeys på ei fast Tailscale HTTPS-adresse. Webserveren lyttar berre lokalt og opnar ingen port direkte på LAN-et.

Kom i gang

Vel kor lenge bakgrunnen skal køyre

Standard er always: meldingar kjem inn også når terminalgrensesnittet er lukka. Vel session dersom daemonen berre skal køyre medan du bruker MeshPi. MeshPi lagrar alle meldingar han tek imot i session-modus, men kan ikkje garantere at noden leverer meldingar som kom medan MeshPi var avslutta.

Linux og Raspberry Pi OS

Installerer under /opt/meshpi og set opp ei avgrensa systemd-teneste (always).

Minimal Debian/Ubuntu kan først trenge sudo apt install curl python3-venv. Installatøren viser rett versjonspakke dersom den valde Python-versjonen manglar venv.

Always – køyrer òg når terminalen er lukka:

curl -fLO https://venes.org/meshpi/install-linux.sh && sudo sh install-linux.sh

Session – køyrer berre medan MeshPi er i bruk, utan sudo:

curl -fLO https://venes.org/meshpi/install-linux.sh && sh install-linux.sh --mode=session

macOS

Installerer for gjeldande brukar og held daemonen i gang med launchd (always).

Always – køyrer òg når terminalen er lukka:

curl -fLO https://venes.org/meshpi/install-macos.sh && sh install-macos.sh

Session – køyrer berre medan MeshPi er i bruk:

curl -fLO https://venes.org/meshpi/install-macos.sh && sh install-macos.sh --mode=session

Windows PowerShell

Installerer per brukar og bruker ein prosessvakt som startar daemonen ved innlogging og etter krasj.

Always – startar ved innlogging og køyrer i bakgrunnen:

Invoke-WebRequest https://venes.org/meshpi/install-windows.ps1 -OutFile install-windows.ps1; .\install-windows.ps1

Session – køyrer berre medan MeshPi er i bruk:

Invoke-WebRequest https://venes.org/meshpi/install-windows.ps1 -OutFile install-windows.ps1; .\install-windows.ps1 -Mode Session

Vel om web skal vere med

Fersk interaktiv installasjon spør først; standard er nei. Bruk --web eller --no-web på Linux/macOS, og -Web Enabled eller -Web Disabled på Windows. Utelat valet ved oppdatering for å bevare oppsettet. Sjå Pi-oppskrifta med web.

Etter installasjon

  1. Opne ein ny terminal.
  2. Køyr meshpi. Ved første oppstart opnar nodeveljaren automatisk.
  3. Vel ei oppdaga TCP-, USB- eller BLE-eining, eller skriv målet manuelt.

Installeren lagar ei ny versjonsmappe, kontrollerer pakken og alle avhengigheiter med SHA-256, køyrer ein offline sjølvtest og byter først deretter. Ved mislykka helsesjekk blir førre versjon sett tilbake automatisk.

Les skriptet før du køyrer det

Dei korte kommandoane over stoler på det serveren leverer akkurat då. Du kan i staden laste ned skriptet, lese det og køyre den lokale fila:

less viser berre fila. Bla med piltastane og trykk q for å lukke visaren før du køyrer neste linje.

sudo apt install curl python3-venv
curl -fLO https://venes.org/meshpi/install-linux.sh
less install-linux.sh
sudo sh install-linux.sh

curl -fLO https://venes.org/meshpi/install-macos.sh
less install-macos.sh
sh install-macos.sh

Invoke-WebRequest https://venes.org/meshpi/install-windows.ps1 -OutFile install-windows.ps1
Get-Content .\install-windows.ps1
Set-ExecutionPolicy -Scope Process Bypass; .\install-windows.ps1

Windows session-modus: .\install-windows.ps1 -Mode Session.

Valfritt webgrensesnitt

Ein fersk Pi, klar for nettlesaren

Køyr kommandoane på 64-bits Raspberry Pi OS med Python 3.11 eller nyare. Berre Pi-en treng installasjonen. Webgrensesnittet er på nynorsk; terminalklienten støttar òg engelsk.

1. Installer med web

sudo apt update && sudo apt install curl python3-venv
curl -fLO https://venes.org/meshpi/install-linux.sh && sudo sh install-linux.sh --web

Opne ein ny terminal etter installasjonen. meshpi web-info viser adressa, rett kodekommando og manuelle oppsettssteg. Oppdatering bevarer avslått web; følg aktiveringsstega som blir viste dersom du vil slå det på. meshpi web-code lagar ein eingongskode som varer i fem minutt. Ein ny kode loggar ut eksisterande websesjonar.

meshpi web-info
meshpi web-code

På Pi-en opnar du http://localhost:8780/meshpi/ og skriv inn koden. Ingen node er førehandsvald. Vel eller legg til ein profil under Tilkoplingar.

2. Pi utan skjerm: bruk ein SSH-tunnel

Køyr dette i ein ny terminal på PC-en og lat tunnelen stå open. Byt USER@PI-HOST med din SSH-brukar og Pi-vert. Opne deretter http://localhost:8780/meshpi/ på PC-en og bruk koden frå Pi-en.

ssh -N -L 8780:127.0.0.1:8780 USER@PI-HOST

Port 8780 må vere ledig på PC-en. Lokal og fjern port skal samsvare med den lagra innloggingsadressa. Oppskrifta gjeld localhost-oppsett; du treng ikkje opne ein LAN-port.

3. Valfritt: Tailscale HTTPS og passkeys

Installer og logg inn i Tailscale på Pi-en og klientane først. Finn Pi-adressa med meshpi web-info. Byt plasshaldaradressa under med den faktiske *.ts.net-adressa. Kontroller tailscale serve status, og bruk berre /meshpi dersom ruta er ledig. Eksisterande ruter skal bevarast.

sudo meshpi web-configure --enable --public-url https://HOST.TAILNET.ts.net --base-path /meshpi
sudo meshpi service enable && sudo meshpi service stop && sudo meshpi service start
tailscale serve status
sudo tailscale serve --bg --set-path /meshpi http://127.0.0.1:8780

--bg held Serve aktivt etter at terminalen blir lukka og etter omstart. Dersom Tailscale ber om HTTPS-aktivering, opnar du lenkja frå kommandoen og følgjer rettleiinga. Kontroller deretter tailscale serve status igjen. Kommandoane er manuelle; MeshPi endrar ikkje Serve-rutene dine.

Tenesteomstart bryt sambandet kortvarig for opne klientar. Opne så https://HOST.TAILNET.ts.net/meshpi/, lag ein ny meshpi web-code, logg inn og vel Innlogging og nøklar → Legg til passkey. Bruk same HTTPS-adresse også på Pi-en. Ny kode eller fjerning av ein nøkkel loggar ut alle nettlesarar.

Du kan lagre fleire namngjevne nøklar i til dømes Bitwarden, Apple Passord eller Windows Hello. Éin eigar har tilgang; separate roller er ikkje med. Passkeys følgjer domenenamnet. Hald tilgangen privat gjennom Tailscale Serve; ikkje bruk Funnel. Les Tailscale-rettleiinga ved oppsett.

4. Vel kor lenge historikken skal lagrast

Opne Innstillingar i webgrensesnittet, eller trykk F10 i terminalen. Kvar tilkopla gateway har eigen database. Nye gatewayar bruker 30 dagar; eksisterande gatewayar ventar på stadfestinga di før ei aldersgrense blir teken i bruk. Du kan sjå og stadfeste manuell rydding av meldingar eller all historikk for gatewayen.

Oppdatering

Signert oppdatering. Ingen datatap.

Etter første installasjon køyrer du meshpi update. Linux i always-modus bruker sudo meshpi update. Eksisterande konfigurasjon, tilkoplingsprofilar og SQLite-historikk blir tekne vare på.

0.9.8 bruker ordinær kanal. Oppdater utan --beta; det blir ikkje laga ein eigen betakanal for webgrensesnittet. Me tek imot feilrapportar og erfaringar før 1.0.0.

pip og Python-biblioteka inne i MeshPi blir oppdaterte gjennom signerte MeshPi-utgivingar. Bruk meshpi update i staden for å oppgradere dei manuelt med pip. Hald Python, operativsystemet og Tailscale oppdaterte separat.

MeshPi sjekkar version.json ved oppstart. Når ein ny versjon finst, blir oppdateringskommandoen vist som ei lokal systemmelding i chatloggen. Han blir aldri sendt til mesh-nettet.

Kontrollert nedlasting

  • Signert manifest og HTTPS utan usignert kommandokøyring
  • Signert storleik og SHA-256 for installatør, pakke og låsefil
  • Offline sjølvtest og automatisk rollback
  • Eksplisitt stadfesting før installasjon
  • Ingen telemetri eller konto

Manifestet er digitalt signert med ein separat RSA-3072-nøkkel som er allowlista i appen og alle installatørane. Endra, ukjende, tilbakekalla eller usignerte manifest blir avviste før pakkar blir installerte. Oppdateraren køyrer aldri ein kommando frå manifestet.

meshpi service status

MeshPi startar ein stoppa daemon ved behov. Når du avsluttar TUI-en, kan du velje om han skal stoppast eller stå att.

Avinstaller utan datatap

Standard avinstallering fjernar program og autostart, men bevarer konfigurasjon, historikk og profilar.

  • Linux / Pi – bruk --purge-data for full sletting
  • macOS – bruk --purge-data for full sletting
  • Windows – bruk -PurgeData for full sletting

Detaljerte mapper, loggkommandoar og drift står i README-en.

Siste versjon

MeshPi 0.9.8

  • Kvar gateway har no sin eigen database. Eksisterande historikk blir flytta til rett gateway, medan den opphavlege databasen blir bevart.
  • Nye gatewayar lagrar historikk i 30 dagar. Vel ei veke, ein månad, eige tal på dagar eller inga aldersgrense. Eksisterande gatewayar bevarer historikken fram til du stadfestar eit lagringsval.
  • Opne Innstillingar i web eller trykk F10 i terminalen. Sjå og stadfest sletting av meldingar eller all historikk for aktiv gateway, etter alder eller uansett alder.
  • Nodedetaljar viser langt namn, kortnamn, ID, maskinvare, rolle, sist høyrd, ekstern straum eller batterinivå, spenning, SNR, RSSI og hopp.
  • Fjerna prototypefoten og knappen for historieksport frå webgrensesnittet. Eksport i terminalen er framleis tilgjengeleg.
  • pip er oppdatert til 26.2.2 i alle plattformlåsene. Installatørane forklarer at MeshPi vedlikeheld desse komponentane og skjuler det misvisande varselet om manuell pip-oppgradering.

Sletting av historikk kan ikkje angrast. Profilar, nodeinformasjon, innloggingsnøklar og radioinnstillingar blir bevarte. Aldersgrensa gjeld meldingar, telemetri, posisjonar og nodehandlingar; den eksisterande meldingsgrensa gjeld òg utan aldersgrense.
