MeshPi beta

Betakanalen er open for alle som ønskjer å prøve dei nyaste forbetringane før neste stabile utgiving.

Beta kan innehalde feil. Bruk den stabile kanalen på maskiner der stabil drift er viktig. Installasjon og oppdatering bevarer konfigurasjon, profilar, SQLite-database og meldingshistorikk.

Oppdater frå MeshPi 0.8.6 eller nyare

Har du MeshPi 0.8.6, 0.8.7 eller ei nyare beta, installerer du siste signerte beta med: 

meshpi update --beta

På Linux i always-modus bruker du sudo meshpi update --beta. --beta gjeld berre denne oppdateringa; vanleg meshpi update held fram med å bruke stabilkanalen.

Full betainstallasjon

MeshPi 0.8.5 og eldre kjenner ikkje --beta. Last då ned og sjå gjennom installatøren før du køyrer han mot betakanalen.

Linux og Raspberry Pi OS

curl -fLO https://venes.org/meshpi/beta/install-linux.sh
less install-linux.sh
sudo env MESHPI_BASE_URL=https://venes.org/meshpi/beta sh install-linux.sh

macOS

curl -fLO https://venes.org/meshpi/beta/install-macos.sh
less install-macos.sh
env MESHPI_BASE_URL=https://venes.org/meshpi/beta sh install-macos.sh

Windows PowerShell

Invoke-WebRequest https://venes.org/meshpi/beta/install-windows.ps1 -OutFile install-windows.ps1
Get-Content .\install-windows.ps1
Set-ExecutionPolicy -Scope Process Bypass
.\install-windows.ps1 -BaseUrl https://venes.org/meshpi/beta

MeshPi 0.8.8b8

Denne betaen ryddar opp i Nodeinfo og samlar dei store chatforbetringane frå 0.8.8-betaane. Databaseformat, radioåtferd og avhengigheiter er uendra frå b7.

  • Telemetri-, posisjons- og traceroutehistorikk viser både dato og tid.
  • Traceroute-knappen viser kor mange sekund som står att av cooldown-perioden.
  • Posisjonsutveksling viser same tydelege nedtelling.
  • Uleste samtalar har heildekkjande lyseblå markering.
  • Direkte samtalar er kompakte og grupperte per kanal.
  • ↑/↓ hentar sendhistorikk, og markert chattekst kan kopierast.
  • Windows-oppdateraren kan byte versjon sjølv om den gamle launcher-fila er låst.

Utan --beta bruker MeshPi alltid den stabile kanalen.
