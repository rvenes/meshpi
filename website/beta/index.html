MeshPi intern beta

Dette er førehandsutgåver for avtalt testing. Dei kan innehalde feil og skal ikkje installerast på maskiner der stabil drift er nødvendig.

Installer siste signerte beta med meshpi update --beta.

MeshPi 0.8.8b2

Ta gjerne ein databaseeksport med meshpi export før du oppdaterer. Denne betaen migrerer databasen til eit nytt skjema.

  • Nodeliste, meldingar, ulest-status og arkiv er skilde per lokal node.
  • Telemetri, posisjon og nodehandlingar er skilde per lokal node.
  • Profilar som koplar til same lokale node, deler framleis historikk.
  • Public-kanalar, inkludert LongFast, har nodebundne samtale-ID-ar.
  • Windows-oppdatering frå 0.8.7 reparerer nødvendige miljøvariablar før Python blir kontrollert.
  • Oppdateraren toler oppryddingsfeil betre og held den manuelle reservevegen på vald kanal.

Utan --beta bruker MeshPi alltid den stabile kanalen.
