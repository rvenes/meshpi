MeshPi betakanal

Betakanalen peikar no på den same signerte MeshPi 0.9.2-utgivinga som stabilkanalen. Eksisterande betabrukarar kan trygt gå vidare til den stabile utgivinga.

Vanleg meshpi update bruker stabilkanalen. Betakanalen blir ståande som ein kompatibel veg vidare for eksisterande betabrukarar. Installasjon og oppdatering bevarer konfigurasjon, profilar, SQLite-database og meldingshistorikk.

Oppdater frå MeshPi 0.8.6 eller nyare

MeshPi 0.8.6 og nyare kan installere den signerte stabile 0.9.2-utgivinga gjennom betakanalen med:

meshpi update --beta

På Linux i always-modus bruker du sudo meshpi update --beta. --beta gjeld berre denne oppdateringa; vanleg meshpi update held fram med å bruke stabilkanalen.

Full betainstallasjon

MeshPi 0.8.5 og eldre kjenner ikkje --beta. Last ned og sjå gjennom installatøren før du køyrer han mot betakanalen.

Linux og Raspberry Pi OS

curl -fLO https://venes.org/meshpi/beta/install-linux.sh
less install-linux.sh
sudo env MESHPI_BASE_URL=https://venes.org/meshpi/beta sh install-linux.sh

macOS

curl -fLO https://venes.org/meshpi/beta/install-macos.sh
less install-macos.sh
env MESHPI_BASE_URL=https://venes.org/meshpi/beta sh install-macos.sh

Windows PowerShell

Invoke-WebRequest https://venes.org/meshpi/beta/install-windows.ps1 -OutFile install-windows.ps1
Get-Content .\install-windows.ps1
Set-ExecutionPolicy -Scope Process Bypass
.\install-windows.ps1 -BaseUrl https://venes.org/meshpi/beta

MeshPi 0.9.2

MeshPi 0.9.2 forbetrar språkbyte, databaserobustheit og logging ved langtidskøyring.

  • Byt språk straks frå F10 eller kommandolinja.
  • Språkvalet per brukar blir lagra atomisk.
  • TUI, CLI, tilkoplingsveljar, feil, installatørar, avinstallatørar og nettside er tospråklege.
  • Eksisterande brukarar utan eit lagra val held fram på nynorsk.
  • Database- og release-manifestformata er uendra.

Utan --beta bruker MeshPi alltid den stabile kanalen.
